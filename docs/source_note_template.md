# Research note template

Keep this template in `docs`, not `sources`; the indexer only reads files in `sources`.

For every historical note added to `sources`, record:

- Topic
- Status: verified fact or attributed historical account
- The claim in your own concise words
- Source organization, publication title, and direct URL
- Date accessed
- Any uncertainty, disagreement, or reuse restrictions

Only add a note to `sources` after checking that its source actually supports the claim. Keep opinions, placeholders, and unsupported notes in `docs/research_needed` until they are verified. Do not copy whole articles.
