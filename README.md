# CoenAI V1

CoenAI is a local, source-grounded conversational portrayal of Dutch footballer Coen Dillen. It runs in a terminal on the visitor's computer; it is not Coen Dillen and does not have his memories.

## How it works

- Ollama runs the Qwen3 1.7B chat model and the Qwen3 embedding model.
- ChromaDB searches the reviewed notes in `sources/` and returns relevant passages to the chat model.
- The answer instructions ask the model to use first person for Coen's documented career, cite source filenames, avoid repeating facts, and say when the notes do not cover a question.
- `index_sources.py` builds the local ChromaDB index from `.md` and `.txt` files in `sources/`.

This is retrieval-augmented generation (RAG), not a model trained on Coen Dillen. Replies can still be mistaken, so review factual answers and their cited sources before public use.

## Run it on Windows

Install [Ollama](https://ollama.com/download), then run these commands in PowerShell from this folder:

```powershell
ollama pull qwen3:1.7b
ollama pull qwen3-embedding:0.6b
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\index_sources.py
.\.venv\Scripts\python.exe .\chat_local.py
```

## Add or update historical information

Create a Markdown note in `sources/`. Use one fact per section and record where and when it was checked. The example format is in `docs/source_note_template.md`. After editing the notes, rerun `index_sources.py` so the local database includes the changes.

`data/chroma/` is generated by the indexing script and is excluded from Git. Rebuild it from the source notes after cloning the project.

## Project files

- `chat_local.py` — terminal conversation and answer behavior
- `index_sources.py` — note chunking and local database indexing
- `sources/` — reviewed fact notes and source links
- `docs/` — character guidance, evaluation checklist, traceability, and a source-note template
- `CoenAI_V1_Portfolio_Snapshot.docx` — project portfolio snapshot
